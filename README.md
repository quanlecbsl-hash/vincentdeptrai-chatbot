# 🧠 Vincentdeptrai: AI Chatbot for English Learners (A1–A2)

Vincentdeptrai is an AI-powered chatbot designed to help students practice English at CEFR A1–A2 levels. It offers grammar correction, vocabulary quizzes, writing prompts, listening and speaking practice—all in one simple web app.

## 🌟 Features

- 🤖 Grammar Correction
- 📚 Vocabulary Quizzes
- ✍️ Writing Practice
- 🔊 Listening Practice
- 🗣️ Speaking Practice
- 🧩 Grammar Exercises
